# GhostSentinel Exclusive

Personal distribution and updater.

Download **GhostSentinel-Updater.zip** from [Releases](https://github.com/SatanLitle/GhostSentinel-Exclusive/releases/latest), extract it, then run **GhostSentinel-Updater.cmd**.

Choose your installation folder, click **Проверить обновления**, then **Обновить патч**. Close the client before installation. Changed files are backed up and verified with SHA256.

Only the supported base installation is accepted. Contact the author if compatibility checks fail.
